Skills Marketplace

A Claude Code plugin marketplace of packaged Claude skills, each installed independently via /plugin. This static list is a fallback; the full interactive site needs JavaScript.

First add the marketplace: /plugin marketplace add HappypsychoX/Skills-Marketplace

Trading Agent

Autonomously trade the Agentic Account via the Robinhood MCP, with standing protective orders, a tunable horizon bias, and a leveraged-ETF screen.

/plugin install trading-agent@skills-marketplace · HappypsychoX/trading-agent

Trading Report

Review a codebase across quality, architecture, performance, security, testing, and documentation, producing a findings report ranked by severity and ROI. Never edits code.
